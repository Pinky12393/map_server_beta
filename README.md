# Active Map Beta 0.2

Серверная бета-версия приложения-карты без отдельной СУБД.

## Что исправлено в 0.2

- формы входа и регистрации больше не отображаются одновременно;
- карта больше не накладывается плитками на экран авторизации;
- добавлено обязательное CSS-правило `[hidden] { display: none !important; }`;
- интерфейс карты полностью переработан в mobile-first стиле;
- добавлены нижняя навигация, плавающие кнопки, панели друзей, слоёв и профиля;
- маркеры друзей показываются как аватары с временем обновления;
- карта открывается на общем виде мира, а спортивные объекты подгружаются после приближения;
- сохранены FastAPI, Leaflet, Overpass API, JSON-хранилище и безопасная авторизация.

## Уже реализовано

- карта Leaflet с подложкой OpenStreetMap;
- серверный прокси к Overpass API;
- спортивные залы, спортцентры, велодорожки, велопарковки и прокат;
- регистрация и вход;
- Argon2-хеширование паролей;
- JWT в `HttpOnly` cookie;
- CSRF-защита изменяющих запросов;
- добавление и подтверждение друзей;
- передача геолокации только подтверждённым друзьям;
- кнопка отключения передачи геолокации;
- обновление точек друзей обычными HTTP-запросами каждые 5 секунд;
- JSON-файл вместо PostgreSQL/MySQL.

## Быстрый запуск

Требуется Python 3.11+.

### Windows PowerShell

```powershell
cd map_beta_server
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:JWT_SECRET = python -c "import secrets; print(secrets.token_urlsafe(64))"
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

### Предпочтительный запуск на Windows (без системного "shim")

В корне проекта добавлены утилиты `run.ps1` и `run.cmd`. Они автоматически создают виртуальное окружение `.venv` (если его нет), устанавливают зависимости и запускают сервер через исполняемый файл Python внутри `.venv`, что позволяет избежать проблем с системными "shim"-путями.

PowerShell:
```powershell
cd map_beta_server
.\run.ps1
```

CMD:
```cmd
cd map_beta_server
run.cmd
```

### Универсальный запуск (любой платформе)

Если вы хотите, чтобы приложение запускалось независимо от установленной версии Python, используйте `run_universal.ps1` / `run_universal.cmd`. Сценарий пытается:

- найти локальный Python, который умеет импортировать `pydantic_core` (т.е. совместимые бинарные колёса), и запустить приложение локально;
- при отсутствии совместимого интерпретатора автоматически создаёт `.venv` и пытается установить зависимости;
- если локальный запуск невозможен, автоматически запускает контейнер через `docker compose up --build`.

PowerShell:
```powershell
cd map_beta_server
.\run_universal.ps1
```

CMD:
```cmd
cd map_beta_server
run_universal.cmd
```



### Linux/macOS

```bash
cd map_beta_server
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export JWT_SECRET="$(python -c 'import secrets; print(secrets.token_urlsafe(64))')"
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Открыть: `http://localhost:8000`

Документация API: `http://localhost:8000/docs`

## Запуск через Docker

1. В `docker-compose.yml` замените `CHANGE_THIS_TO_A_LONG_RANDOM_VALUE`.
2. Выполните:

```bash
docker compose up --build
```

## Проверка друзей

1. Откройте приложение в обычном окне браузера и зарегистрируйте первого пользователя.
2. Откройте приватное окно и зарегистрируйте второго.
3. Первый отправляет заявку по email второго.
4. Второй принимает заявку.
5. Оба включают передачу геолокации.

## Ограничения бета-версии

- Все данные лежат в `data/state.json`.
- Сервер должен работать в одном процессе без нескольких `uvicorn workers`.
- Нет восстановления пароля и подтверждения email.
- Нет refresh-токена и отзыва активных сессий.
- Геолокация на удалённом сервере требует HTTPS. На `localhost` обычно работает без него.
- Спортивные объекты подгружаются начиная примерно с масштаба района/города.
