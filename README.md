# 🗺️ Active Map Beta Server

Бэкенд и веб-интерфейс для интерактивной карты с возможностью отслеживания геолокации друзей и поиска спортивных/велосипедных объектов в реальном времени.

## ✨ Основные возможности

*   **Аутентификация и безопасность:** JWT-токены, безопасное хеширование паролей (`pwdlib`), защита от CSRF и XSS.
*   **Социальные функции:** Система заявок в друзья, просмотр списка друзей и удаление из друзей.
*   **Геолокация:** Обмен местоположением с друзьями (с возможностью отключить в настройках приватности). Координаты старше 1 часа не отображаются.
*   **Интеграция с картами:** Запрос объектов (фитнес-центры, велодорожки, парковки) через OpenStreetMap (Overpass API) с кэшированием для экономии ресурсов.
*   **Без СУБД:** Для бета-версии используется быстрое файловое хранилище (JSON) с асинхронной блокировкой.

## 🛠️ Технологии

*   **Backend:** Python 3.10+, FastAPI, Uvicorn
*   **Валидация:** Pydantic
*   **Работа с HTTP:** HTTPX (асинхронные запросы к Overpass API)
*   **Безопасность:** PyJWT, pwdlib
*   **Развертывание:** Docker, Docker Compose

## 🚀 Быстрый старт (Локально)

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/Pinky12393/map_server_beta.git
   cd map_server_beta
Создайте виртуальное окружение и установите зависимости:

bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

pip install -r requirements.txt
Настройте переменные окружения:
Скопируйте .env.example в .env и укажите свои значения:

bash
cp .env.example .env
Обязательно задайте надежный JWT_SECRET (не менее 32 символов).

Запустите сервер:

bash
uvicorn app.main:app --reload
Сервер будет доступен по адресу: http://127.0.0.1:8000

🐳 Запуск через Docker
Если у вас установлен Docker и Docker Compose, просто выполните:

bash
docker-compose up -d --build
⚙️ Переменные окружения (.env)
Переменная	Описание	По умолчанию
JWT_SECRET	Секретный ключ для подписи токенов (мин. 32 символа)	Генерируется случайно
ACCESS_TOKEN_MINUTES	Время жизни токена (в минутах)	60
COOKIE_SECURE	Использовать куки только по HTTPS	false
DATA_DIR	Путь к папке для хранения данных	./data
OVERPASS_URL	URL API OpenStreetMap	https://overpass-api.de/api/interpreter
